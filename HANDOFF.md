## Решения и ограничения

- Выкладка только по явному «выкатывай» Александра, на каждый деплой.
- Docker локально нет; бот локально не запускать (подхватит боевой `.env`).
- Приёмка — тесты и смоук на проде, руками Александр не проверяет.
- Порядок и исполнитель хранятся в заметке (решение Александра 28.10);
  исполнителей два, «черновик» = агент + рекомендация. Номер — только на
  сегодня; порядок на завтра в вечернем ритуале и номера просроченным — вне
  объёма. После закрытия задачи номера не перенумеровываются.
- Рекомендации — указания для агента только из блока; текст заметки над
  блоком (форварды) — чужой.
- `../todo_and_run` не под git — его `todo.py` правит только соседний агент.
- `ASSISTANT_API_TOKEN` — в `.env` vps4 и Mac; в `.env.example` не добавляем.
- Graph хранит у задач только дату; время — из напоминаний бота и событий.

## Блокеры и риски

- Утреннее сохранение плана — до 10 пар GET+PATCH в Graph подряд; у
  изменённых задач меняется «изменено» в To Do.
- Окно между GET и PATCH без If-Match: правка в To Do в эту секунду может
  потеряться (риск принят).
- Если соседний агент повторит парсер в `todo.py` по-своему, правила
  разойдутся — общие случаи в `tests/fixtures/task_meta_cases.json`.
- Не проверено живьём: сводка ритуала с кнопкой, Graph `reminderDateTime`
  round-trip, nginx-лимит 300k на большом материале.
- Из аудита (`AUDIT-2026-10-26.md`) открыто: `USER` в Dockerfile,
  healthcheck, `dp.errors`, тихие `except`, закрепление версий, статистика
