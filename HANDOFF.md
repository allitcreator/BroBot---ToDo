## Текущее состояние

Решения Александра по ритуалу:
- разбор **утром и вечером**; время каждого настраивается (по умолчанию
  9:30 и 20:30, `Europe/Moscow`), каждую сводку можно выключить;
- запуск — **бот присылает сводку** с кнопкой, только если есть что решать;
- отдельный шаг **«Застряло»** (открытые старше 14 дней, ≤3 за утро);
- **недельного обзора не надо**;
- сводки в выходные — по умолчанию выключены (в макете, не подтверждено явно).

Паттерн использования (метаданные MS To Do за 90 дней, без названий):
~3–4 новые задачи в день, пн — 81 задача против 43–53 в другие будни, в
сб–вс 16–19; пики создания 10–13 и 17–22; закрыто 297 из 313, закрытия в
46 днях из 90, медиана 5 в день; 7 из 17 открытых старше 19 дней;
задач с заметкой (форварды) ~24 за 90 дней. Graph хранит дату выполнения
без времени — «во сколько закрывает» не узнать.

Утро (шаги, пустые пропускаются): 1) Просрочено — списком, главная кнопка
«Остальное на сегодня»; 2) Застряло — по одной карточке: Сегодня / Через
2 недели / В проект / Удалить; 3) Входящие — по одной карточке с источником:
Сегодня / Дата / В проект / Удалить; 4) План дня — встречи из Google
Calendar + задачи + сравнение с нормой (медиана 5). Днём — обычный экран
«Сегодня» с плашкой «N новых во входящих».

Вечер (только если на сегодня остались открытые): 1) «Что успел?» —
отметить сделанное; 2) «Остальное на завтра» одной кнопкой, день меняется
у любой; превью завтра. Затем экран «День закрыт» с итогами.

## Решения и ограничения

- Graph хранит у задач только дату (полночь UTC), времени нет — время
  берётся из напоминаний бота и событий Google Calendar.
- Фоновый цикл в `bot.py` (`_reminder_loop`, каждые 30 с) — место для
  планировщика сводок; рестарт в момент сводки не должен давать дубль
  (хранить «последняя отправка» в БД).
- Открытие ритуала из сводки — web_app-кнопка с параметром (например
  `?start=morning`), обычный вход — экран «Сегодня».
- «Через 2 недели» — дата +14 дней, задача остаётся в To Do.
- Выкатка в прод блокируется auto-режимом без явного «выкатывай» от
  Александра — на каждый деплой спрашивать.
- Docker локально нет; бот локально не запускать (подхватит боевой `.env`).
