ToDoBOT — 4 концепции мини-аппа

Каждая концепция выросла из конкретного аналога и по-разному отвечает на один вопрос: как прожить «закинул в чат → разобрал → сделал». Оформление везде одно — родное для Telegram: цвета темы, системная шапка с «Закрыть», главная синяя кнопка снизу, линейные иконки вместо эмодзи.

A. Мой день

Аналоги: Microsoft To Do «Мой день» + Things 3 «Today»

Главный экран — одна осознанная страница дня: сверху мелко события из Google Календаря, ниже задачи, выполненные тихо уходят вниз зачёркнутыми. Входящие и просроченные — не отдельная вкладка, а «предложения» под лампочкой: открыл лист, нажал «＋» — задача в дне. Главная кнопка Telegram внизу всегда про одно действие. Минимум вкладок: День · Неделя · Проекты.

B. Утренний разбор

Аналоги: Sunsama (утренний ритуал) + разбор по одной карточке

Мини-апп открывается не списком, а ритуалом на две минуты: три шага с прогрессом сверху — «просроченное», «входящие», «план дня». Входящие идут крупной карточкой по одной: видно, что переслано и откуда, ниже четыре решения, включая «В проект». Главная кнопка Telegram ведёт по шагам. Когда разобрано — экран итогов и обычный список дня. Утренняя сводка от бота открывает именно этот ритуал.

C. Неделя-блокнот

Аналоги: Tweek / TeuxDeux (бумажная неделя) + Todoist Upcoming (полоса дней)

Главный экран — неделя как ежедневник: сверху полоса дней с точками (красная — есть просроченное), ниже лента по дням без часов. Задачу перетаскиваешь пальцем на другой день. Входящие живут шторкой снизу — «Когда-нибудь / разобрать»: вытянул карточку из шторки на нужный день — разобрал. Ничего не прячется по вкладкам: вся неделя и склад на одном экране.

D. Лента дня

Аналог: Structured (визуальная лента дня) + события Google Календаря, которые у бота уже есть

День нарисован вертикальной лентой времени: встречи из календаря — зелёные блоки, задачи с напоминанием встают на своё время, красная линия «сейчас». Задачи без времени — сверху в блоке «В любое время». Свободные окна видны пунктиром — можно бросить туда задачу из входящих. Самый наглядный вариант, если календарь у тебя живой; если встреч мало, лента будет пустоватой.
