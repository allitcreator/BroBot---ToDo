ToDoBOT — 5 вариантов UI по аналогам

Структура везде одна, уже в проде, без проектов: «Сегодня» с входом в ритуалы и плашкой входящих, шаг утреннего разбора, закрытие дня. Меняется визуальный язык — каждый вариант заимствует его у конкретного приложения. Задачи выдуманные. Мини-апп живёт внутри Telegram, поэтому у каждого варианта есть тёмная тема (не нарисована, но цвета для неё подбираются из темы Telegram).

1. Как Things 3 — тихий и воздушный

Things 3 (Cultured Code): белый фон, крупный заголовок со звездой «Today», скруглённые квадратные чекбоксы, группы отделены тонкой линией, почти нет цвета — синий только у действий. Разбор по одной — большая карточка, как «Quick Find / Magic Plus»: одно решение за раз.

2. Как Todoist — плотный и деловой

Todoist (Doist): список на всю ширину с разделителями, кружок-чекбокс цвета приоритета, под названием — чипы даты и источника, секция «Просрочено» с красной ссылкой «Перенести», красная кнопка «+». Разбор — как экран задачи Todoist: поля «Дата / Создана / Напоминание» и действия списком.

3. Как Microsoft To Do «Мой день» — фон и подсказки

Microsoft To Do: «Мой день» с фоновой картинкой, крупная дата в шапке, полупрозрачные строки задач, лампочка «Предложения» — нижний лист с задачами, которые стоит взять сегодня. У нас «Предложения» и есть утренний разбор: просроченные, застрявшие, входящие с кнопками. Задачи и так лежат в MS To Do — визуальная преемственность.

4. Как Structured — день как шкала времени

Structured (Leon Schmid): лента недели сверху, вертикальная пунктирная шкала, у каждого события цветная «капсула» с иконкой и временем, задачи без времени — в блоке «В любое время». Тёплый фон, крупные скругления. Разбор — большие цветные карточки и плитки-решения.

5. Как Apple «Напоминания» — нативный iOS

Apple Reminders и «Настройки» iOS: серый фон, белые скруглённые группы (inset grouped), плитки-счётчики «Сегодня / Запланировано / Все / С флажком» сверху, синий системный акцент, кружки-чекбоксы. Разбор — как экран детали напоминания: ячейки, сегменты, системная синяя кнопка. Ощущается частью телефона.
